## 🚀 طريقة التركيب · 3 خطوات

### الخطوة 1 · ارفعي الملفات على GitHub

**الطريقة الأسهل · من المتصفح:**

1. افتحي الريبو على GitHub
2. اضغطي **Add file → Upload files**
3. **اسحبي كامل مجلّد `src/`** من هذا الـZIP (بعد فكّه) إلى منطقة الرفع
4. GitHub راح يحفظ الهيكل تلقائياً
5. كرّري نفس الشي للـمجلّدات التانية:
   - `supabase/` (فيه ملف SQL)
   - `vercel.json` (ملف واحد)

**💡 ملاحظة:** إذا GitHub حذّرك إنه راح يستبدل ملفات موجودة → **خلّيه يستبدلها** (هذا المطلوب).

**Commit message:**
```
🎁 Phase 1: Customer Experience Pack
- Favorites system
- Repeat last booking
- Birthday coupons via WhatsApp
- Reviews with photos
```

---

### الخطوة 2 · شغّلي الـSQL في Supabase

1. افتحي **Supabase → مشروعك → SQL Editor → New Query**
2. انسخي محتوى `supabase/migrations/20261020_customer_experience.sql`
3. الصقي → اضغطي **Run**
4. المفروض يطلع تقرير بـ 5 أسطر `true` ✅

### الخطوة 3 · أنشئي Storage Bucket للصور

1. Supabase → **Storage** (في القائمة اليسار)
2. **New Bucket**
3. الاسم: `reviews`
4. ✅ **Public bucket** (لازم تحطّين الصح)
5. **Create**

### الخطوة 4 · انتظري Vercel ينشر (تلقائي · ~2 دقيقة)

بعد الـcommit على GitHub · Vercel راح ينشر تلقائي.

## 🔔 (اختياري) تفعيل الكرون اليومي

عشان كوبون عيد الميلاد يرسل تلقائي كل يوم الساعة 9 صباحاً:

1. Vercel → **Settings → Environment Variables**
2. أضيفي:
   - **Name:** `CRON_SECRET`
   - **Value:** أي نص عشوائي طويل (مثلاً: `bfl-cron-secret-xk8d9m2p`)
3. **Save** → **Redeploy**

Vercel Cron راح يستدعي `/api/cron/birthday-coupons` كل يوم تلقائي.
