## 🚀 الخطوات بالتفصيل

### الخطوة 1 · إنشاء Business Manager

1. ادخلي على: **https://business.facebook.com**
2. اضغطي **"إنشاء حساب"**
3. أدخلي:
   - اسم العمل: **The First Lady** (أو **صالون السيّدة الأولى**)
   - اسمكِ الكامل
   - بريدكِ الإلكتروني (بريد الصالون الرسمي)
4. اضغطي **"إرسال"** → ستصلكِ رسالة تأكيد على البريد.

### الخطوة 2 · إعداد WhatsApp Business

1. من الـBusiness Manager → **الإعدادات** (⚙️)
2. **حسابات → WhatsApp Accounts** → **إضافة**
3. اضغطي **"بدء"** → ستُحوّلين لصفحة إعداد واتساب
4. اختاري **"إنشاء حساب WhatsApp Business جديد"**
5. أدخلي:
   - اسم العرض: **The First Lady** (هذا ما تشوفه العميلات)
   - الفئة: **Beauty, Spa & Salon**
   - الوصف: **صالون نسائي راقٍ في المدينة المنوّرة**

### الخطوة 3 · ربط رقم الجوّال

1. أدخلي رقم الجوّال اللي بتستخدمينه لواتساب الصالون
   - **مهمّ:** هذا الرقم لا يكون موجود في واتساب شخصي
   - لو كان مستخدم · احذفيه من واتساب أوّلاً (الإعدادات → الحساب → حذف)
2. Meta ترسل رمز تحقّق عبر **SMS أو مكالمة**
3. أدخلي الرمز → ✅ تمّ الربط

### الخطوة 4 · الحصول على المفاتيح (Access Token + Phone Number ID)

1. ادخلي على: **https://developers.facebook.com/apps**
2. اضغطي **"إنشاء تطبيق"** → اختاري **"Business"**
3. أدخلي اسم التطبيق: **The First Lady Salon**
4. من الـDashboard → اختاري **"WhatsApp"** → **"Set up"**
5. ستجدين قسم **"Temporary access token"** → **انسخيه** (يبقى 24 ساعة فقط)
6. تحت الـtoken · تجدين **"Phone number ID"** → **انسخيه كمان**

### الخطوة 5 · إضافة المفاتيح في النظام

1. ادخلي على: **https://vercel.com** → اختاري مشروع **The First Lady**
2. **Settings → Environment Variables**
3. أضيفي:
   ```
   WHATSAPP_PROVIDER = meta
   WHATSAPP_PHONE_NUMBER_ID = (اللي نسختيه في الخطوة 4)
   WHATSAPP_ACCESS_TOKEN = (اللي نسختيه في الخطوة 4)
   ```
4. اضغطي **Save** → ثمّ **Deployments → Redeploy** آخر deploy

### الخطوة 6 · اختبار

1. اطلبي من أيّ صديقة تسجّل دخول بحسابها في موقعكِ
2. ستصلها رسالة OTP من **The First Lady** على واتساب
3. ✅ النظام شغّال!

## 🔑 Token دائم (مهمّ)

الـTemporary Token يموت بعد 24 ساعة. للـToken الدائم:

1. من Facebook Developers → **تطبيقكِ → Business Settings**
2. **System Users** → **Add** → أدخلي اسم (مثلاً: TFL System)
3. **Assign Assets** → اختاري **WhatsApp Business Account**
4. **Generate New Token** → اختاري صلاحيّات:
   - `whatsapp_business_messaging` ✓
   - `whatsapp_business_management` ✓
5. **Expiration: Never** → **Generate**
6. انسخي الـToken الجديد · حدّثي قيمة `WHATSAPP_ACCESS_TOKEN` في Vercel
